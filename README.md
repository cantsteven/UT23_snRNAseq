# Guerin et al., 2025: UT23_snRNAseq Publication
## Overview
This repository contains code for the data analysis of (publication name) (Guerin et al., 2025)

There are two quarto documents used for this analysis: 
### UT23_scRNAseq.qmd 

This Quarto file documents the single-nucleus RNA-seq analysis workflow using the Seurat package in R. It covers the steps from data import (reading .h5 count matrices), sample metadata annotation, quality control, filtering, normalization, batch integration with Harmony, clustering, marker gene identification, initial visualization, cell type annotation, and saving processed data objects.
